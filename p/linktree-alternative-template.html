Deploy ke GitHub Pages dalam 3 Langkah

  1. Buat repository baru di GitHub bernama linktree (atau username.github.io).
  2. Upload file index.html dan gambar avatar Anda.
  3. Buka menu Settings ➔ Pages di GitHub, pilih branch main, dan klik Save. Website Anda langsung live di internet dalam 30 detik!
